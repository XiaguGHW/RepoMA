# Experimente

Dieser Ordner enthält klar abgegrenzte Testläufe und Varianten der Klassifikation.

- `Gemini_HBG_classification_test.py`: erster Test mit 10 Baugruppen und Priority-1-Dateien
- `Gemini_HBG_classification_P1_20.py`: 20 Baugruppen mit Priority-1-Dateien
- `Gemini_HBG_classification_P1_P2_20.py`: 20 Baugruppen mit Priority-1- und Priority-2-Dateien
- `test_excel_upload.py`: technischer Test für den Excel-Dateiupload

Die Skripte sollten aus dem Repository-Hauptordner gestartet werden, damit sie den lokalen `input/`-Ordner finden.
